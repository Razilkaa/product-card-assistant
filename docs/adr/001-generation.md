# Решения по архитектуре

Статус: принято, 03.11.2026.

FastAPI и один вызов LLM на товар. База данных и очередь не нужны для одиночных запросов из ТЗ.

Характеристики копируются из входа. Модель пишет текст; Pydantic проверяет формат и длину, отдельная проверка отклоняет новые числа. Промпт запрещает догадки и выполнение инструкций из данных товара.

Ошибки входа возвращают 422, ошибки генерации — 502. Повторов нет, чтобы не увеличивать расходы без ведома пользователя.

Ограничения: проверка чисел не гарантирует достоверность текста; перед публикацией нужна проверка менеджером. Обязательные характеристики зависят от категории прибора. Следующий шаг — схемы полей по категориям и проверка фактов на размеченных примерах.

Зависимости фиксируются в uv.lock. Разработка, CI и Docker используют uv. Контейнер запускается без root; секреты передаются через окружение.
